# CafeTycoon

A small cafe-management game built for fun by a few friends. Play it in the browser.

**Play:** https://snowmexican7.github.io/CafeTycoon/

## Working on it

- Clone the repo, commit to `main`, push. GitHub Pages republishes the site from `main` automatically.
- Pull before you push.
- Never commit secrets or assets we don't have the right to share. The repo and the game are public.
