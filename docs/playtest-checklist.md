# Playtest checklist: phase 1a (solo)

Run this on the live site, https://snowmexican7.github.io/CafeTycoon/, in one browser.
Tick each box as you go. Open the browser console first and leave it open: the last
line asks whether it stayed clean.

- [ ] Title screen shows, with past runs (or "No runs yet").
- [ ] Enter seed `1234`, keep pace 3 and 150 s, press **Start solo run**.
- [ ] The first night shows a 60 s countdown, $100, five cards, and the restock buttons.
- [ ] Buy the cheapest card. Cash drops by its cost and the card disappears.
- [ ] Press **Open the shop**. The day starts, and the toast shows the scenario note and the item you bought.
- [ ] WASD moves the barista; it stops at walls and at stations.
- [ ] Stand next to the grinder and press E. Beans drop by one and a progress bar fills.
- [ ] Press E again when it finishes: the barista holds grounds (small brown circle).
- [ ] Grounds into the espresso machine, espresso into the steamer: milk drops by one and a latte comes out.
- [ ] Serve a drink to a matching customer at the counter: cash goes up and the customer leaves.
- [ ] Let a customer's patience run out: they vanish, and the closing summary counts them as stormed out.
- [ ] Buy beans down to zero (or trash grounds until beans run out): Espresso and Latte go strikethrough in the HUD and no customer orders them.
- [ ] Press Esc mid-day and change the pace to 5. New customers arrive faster; the queue fills.
- [ ] Refresh the page mid-day. The title shows **Resume run**; resuming continues the same day with the same cash.
- [ ] The closing summary shows served, stormed out, sales, tips, rent, profit, and the reputation change.
- [ ] Night 2 shows yesterday's takings and a different hand.
- [ ] Reach day 7 (or set day length to 60 s to get there faster). The week-end screen shows the score and the seed.
- [ ] Press **Keep going**. Night 8 starts, the HUD says "week 2", and rent on the next closing is higher.
- [ ] Press Esc, **Quit to title**, then **Resume run**: the run continues.
- [ ] Finish with **See score & stop** (or go bankrupt). The run appears at the top of past runs.
- [ ] Start a new run with no seed: the scenario or the first hand differs from the seeded run.
- [ ] The browser console shows no errors for the whole session.
